# Readout 2.0 on readkit: progress log

Read this first when resuming. Owner: the v2 builder. readkit is vendored at `readkit/`
(v0.1.0, do not edit it; readkit bugs go under "readkit issues" below).

Rules: headless Chrome only (`--headless=new`, fresh temp profile); kill only the test
processes you start (the user's own Chrome is running); never commit; never write the
READKIT_SCRATCH / READKIT_PRIVATE paths into files; no model files or GPL code in the repo.

Test env (set in the shell, never in files): READKIT_SCRATCH, READKIT_PRIVATE.

## Plan (milestones)

1. core.js: drop chunkText/speakable/stripRepeats/cleanOcr; segment helpers (findSegment,
   prefixLengths, headings), lexicon helpers, prefs sync file (readout-prefs.json: the
   pronunciation list, newer wins; old clients ignore and never delete it). Unit tests.
2. app.js text pipeline: readkit loaded with import() at start; plan() segments (lexicon,
   dialect, skip citations) -> reader spans; positions per segment (same stored format);
   Device engine (speechSynthesis) speaks seg.spoken with align-mapped word highlights;
   files through extract() (allowOcr = old consent sheet, progress + Stop with AbortController,
   blocks kept from onBlock on Stop); textFromDoc(doc, includeNotes).
3. Voices: Natural (Kokoro), Standard (Piper), Device. Download sheet (size, Wi-Fi, free
   space), voiceStore install/resume/remove, createVoice + calibrate, fallback chain
   natural -> standard -> device. readkit createPlayer on one persistent <audio>;
   onSegment/onWord highlight; seek/scrub/tap; setSpeed; finish; errors -> Device.
   Dev override ?local=<loopback model server> (both loopback only).
4. sw.js: COOP same-origin + COEP credentialless + CORP on same-origin responses; reload once
   when not isolated; precache shell + readkit runtime list (tools/readkit-files.mjs keeps the
   list in sw.js; a unit test checks it); CDN cache-first (no-cors -> cors fetch);
   share target POST (Cache Storage + 303 to ./?shared=1); manifest share_target POST.
5. Daily features: sleep timer (fade, screen off), auto-next, headings list, pronunciation
   list (synced), Save audio (Ogg from the clip cache), remove the silent-audio toggle.
6. Tests: core/sync unit, sync.e2e, pdf.e2e (new pipeline), v2.e2e (scan, highlight plan,
   Piper + Kokoro hidden with freezing >= 60 s, Device fallback, Media Session, sleep timer,
   share POST, settings at 360 px, console).
7. README, VERSION 2.0.0, ?v= bumps.

## readkit issues (to report, not fixed here)

- DESIGN.md says `player.exportOgg() -> Blob`; the code returns `{ blob, missing, packets }`.
- src/pdf/pdf.js: an image-only scanned page with only one or two short lines of print (ink
  share under INK = 0.008, e.g. the last page of a chapter) is taken for a blank page: not
  OCR'd, no warning, its text silently missing (4-page scan with 2-line pages 3-4: stats
  ocrPages 2 of 4). pdf.e2e works around it with fuller pages.
- OCR layout: lines printed at 1.6x line spacing ("...but all" / "of them trusted...") come out
  as separate paragraphs even when the next line starts in lower case.
- player.js produce(): a voice whose synth() rejects with an AbortError nobody asked for (a
  disposed voice: voice.js kill(abortError())) is treated as a cancel and retried at once,
  forever (a hot async loop, state stays 'buffering'). Readout never disposes a voice under a
  live player and has its own stall watchdog.
- plan(): a lexicon entry for a name after "Dr." ('Patel' -> 'Puh-tell') stops "Dr." from being
  expanded ("Dr. Puh-tell", not "Doctor ..."): the placeholder hides the capital the rule needs.
